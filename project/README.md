# Расчёт ротора ЦНС 105-392 (5МС-10)

Пакет содержит расчётную модель ротора насоса ЦНС 105-392 с гидродинамическими подшипниками скольжения, полной матрицей опоры 2×2, щелевыми уплотнениями по модели Ломакина и индивидуальными массами рабочих колёс.

## Состав

- `models/parameters.py` -- исходные параметры насоса, подшипников, ротора, рабочих колёс и щелевых уплотнений.
- `models/bearing.py` -- решение уравнения Рейнольдса и расчёт коэффициентов подшипника.
- `models/rotor.py` -- балочная модель ротора в двух плоскостях, комплексная собственная задача и расчёт орбит.
- `scripts/run_all.py` -- пересчёт таблиц и графиков.
- `data/` -- численные результаты расчёта.
- `figures/` -- графики для включения в текст ВКР; расчётная схема сохраняется в PNG и SVG (`06_rotor_scheme_with_seals.*`).
- `Koleso2.pdf` -- чертёж рабочего колеса первой ступени ЦНС 90.00.00.012, использованный для массы, геометрии и допустимого дисбаланса.

## Основные исходные данные

- Насос: ЦНС 105-392, заводское обозначение 5МС-10.
- Подача: 105 м³/ч.
- Напор: 392 м.
- Частота вращения: 2950 об/мин.
- Число ступеней: 8.
- Подшипники: шейка 90 мм, длина вкладыша 40 мм, средний радиальный зазор 53,5 мкм.
- Рабочее колесо первой ступени по чертежу ЦНС 90.00.00.012: `D2 = 300 мм`, `B2 = 22,4 мм`, 7 лопастей, Сталь 45, масса `19,6 кг`, допустимый дисбаланс `250 г·мм`.
- Промежуточные рабочие колёса: `16,0 кг` по расчётной инженерной оценке.
- Последняя ступень: в имеющейся спецификации относится к группе поз. 11, поэтому в расчёте принята как колесо группы промежуточных ступеней, `16,0 кг`.
- Массовый ряд колёс: `19,6 + 7 × 16,0 = 131,6 кг`.
- Расчётная масса вала между опорами: `97,43 кг`.
- Полная расчётная масса ротора: `229,03 кг`.

## Принятые допущения по колёсам

Чертёж есть только для колеса первой ступени. В спецификации сборочного чертежа выделены две позиции: поз. 12 -- колесо первой ступени, 1 шт.; поз. 11 -- рабочее колесо остальных ступеней, 7 шт. Отдельного чертежа поз. 11 в материалах нет, поэтому масса этих колёс принята расчётно как 16,0 кг. Значение выбрано внутри ожидаемого диапазона для секционных насосов и примерно на 18% ниже массы первого колеса, так как промежуточные колёса имеют отличающуюся отливку и не содержат части входных элементов.

## Статическое равновесие подшипников

Эксцентриситет подшипника не задаётся фиксированным числом. В расчёте сначала определяются реакции опор от собственного веса ротора, затем по зависимости несущей способности масляной плёнки от эксцентриситета решается уравнение равновесия.

Полученные реакции:

- левая опора: `W1 = 1184,82 Н`;
- правая опора: `W2 = 1061,98 Н`.

Рабочие эксцентриситеты:

- левая опора: `epsilon_left = 0,35965`;
- правая опора: `epsilon_right = 0,33442`;
- среднее значение для иллюстративных графиков давления: `epsilon_mean = 0,34704`.

## Гидравлическая радиальная сила

Сила потока рассчитывается по инженерной зависимости

```text
F_rad = K_R * rho * g * H * D2 * B2
```

где `D2 = 0,300 м`, `B2 = 0,0224 м` взяты с чертежа колеса первой ступени. Для номинального режима принято `K_R = 0,020`, для нерасчётного режима при отклонении подачи -- `K_R = 0,040`.

Полученные суммарные силы:

- номинальный режим: `516,84 Н`;
- нерасчётный режим: `1033,68 Н`.

В упругой модели эта суммарная сила распределяется по узлам рабочих колёс.

## Дисбаланс

Основные сценарии используют классы балансировки по ГОСТ ИСО 1940-1-2007:

- `G6,3` -- новый ротор;
- `G16` -- предельно допустимое расчётное состояние.

Допустимый дисбаланс с чертежа первого колеса `250 г·мм` используется как независимая проверка уровня возбуждения. При `n = 2950 об/мин` он даёт силу `23,86 Н`. Для сравнения, класс G6,3 для промежуточного колеса массой 16,0 кг даёт `31,14 Н`, а для первого колеса соответствует допустимому дисбалансу около `399,71 г·мм`. Поэтому чертёжное значение находится в том же порядке и не противоречит выбранному классу балансировки.

## Щелевые уплотнения и коэффициенты Ломакина

Геометрия щелевых уплотнений задана явно в `models/parameters.py`:

- переднее щелевое уплотнение рабочего колеса: `D_s = 110 мм`, `gamma_s = 0,40`;
- заднее щелевое уплотнение рабочего колеса: `D_s = 195 мм`, `gamma_s = 0,60`;
- щелевое уплотнение разгрузочного устройства: `D_s = 120 мм`, `gamma_s = 0,30`;
- длина ступеневого щелевого уплотнения: `L_s = 10 мм`;
- радиальный зазор нового насоса: `c_s = 0,20 мм`;
- коэффициент Ломакина: `lambda_L = 0,55`;
- коэффициент демпфирования: `beta_s = 0,25`.

Для изношенного состояния используются эффективные зазоры 0,30--0,40 мм через множители в сценариях расчёта.

## Эксплуатационные сценарии

В расчёте используются три варианта:

1. Новый ротор: класс G6,3 и гидравлическая радиальная сила на номинальном режиме.
2. Допустимый эксплуатационный износ: G6,3, увеличенная гидравлическая сила на нерасчётном режиме, радиальный зазор подшипника ×1,4, зазор щелевых уплотнений ×1,5.
3. Предельно допустимый проверочный вариант: G16, увеличенная гидравлическая сила, радиальный зазор подшипника ×1,5, зазор щелевых уплотнений ×2,0.

## Ключевые результаты пересчёта

- Первая пара частот без щелевых уплотнений: `1629,3 / 1634,2 об/мин`.
- Первая пара частот с номинальными щелевыми уплотнениями: `3701,8 / 3705,7 об/мин`.
- Первая пара частот для предельно допустимого варианта G16 с увеличенными зазорами: `2900,0 / 2901,6 об/мин`.
- Логарифмический декремент первой ветви: `0,757` для нового ротора, `0,638` при допустимом износе, `0,400` для варианта G16.
- Минимальный логарифмический декремент первых трёх ветвей: `0,504`, `0,138`, `-0,053`; отрицательное значение в варианте G16 соответствует потере запаса устойчивости по третьей ветви.
- Запас по первой критической скорости относительно 2950 об/мин: `25,5%`, `8,4%`, `1,7%` для трёх сценариев соответственно.
- Виброскорость в опорном сечении по большой полуоси орбиты: `0,47`, `5,75`, `13,99 мм/с`; соответствующие зоны по укрупнённой шкале ISO/GOST 20816: `A`, `C`, `D`.
- Полуоси орбиты центрального сечения:
  - G6,3 + номинальная сила: `51,60 / 26,95 мкм`;
  - G6,3 + допустимый износ: `252,20 / 121,03 мкм`;
  - G16 + предельные зазоры: `488,38 / 285,49 мкм`.
- Максимальный угол перекоса шейки: `0,098 мрад` для нового ротора и `0,840 мрад` для предельно допустимого варианта.
- Максимальное давление при перекосе в предельно допустимом варианте возрастает с `0,685` до `0,897 МПа`.

## Анализ устойчивости и нормативная оценка

Устойчивость оценивается по собственным значениям матрицы системы первого порядка. Для каждой ветви рассчитывается действительная часть собственного значения и логарифмический декремент. Система считается имеющей динамический запас, если интересующие низшие ветви имеют отрицательные действительные части, а логарифмический декремент остаётся положительным и не ниже инженерного критерия `0,1`.

Результаты сохранены в файлах:

- `data/stability_summary.csv` -- сводка по первой ветви и минимуму декремента первых трёх ветвей;
- `data/stability_modes.csv` -- первые три ветви для каждого эксплуатационного сценария;
- `data/normative_comparison.csv` -- сопоставление с запасом по критической скорости и зонами виброскорости;
- `data/support_vibration_velocity.csv` -- пересчёт полуосей опорных орбит в среднеквадратичную виброскорость;
- `figures/17_log_decrement_stability.png` -- график логарифмического декремента.

Практическая интерпретация: новый ротор имеет достаточный частотный и вибрационный запас; при допустимом износе устойчивость сохраняется, но запас до первой критической скорости становится недостаточным; предельный вариант G16 с увеличенными зазорами близок к рабочей частоте и требует вывода в ремонт.

## Запуск

```bash
pip install -r requirements.txt
python scripts/run_all.py
```

После запуска обновляются файлы в `data/`, `figures/` и `validation/`.
